# موقع ستركونيك للمقاولات

موقع الشركة مبني بـ Next.js 14 + TypeScript + Tailwind CSS + Framer Motion + Lucide Icons، بواجهة عربية بالكامل واتجاه RTL.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000

## البناء للإنتاج

```bash
npm run build
npm run start
```

## هيكل المشروع

```
app/                  صفحات Next.js (App Router)
  layout.tsx          التخطيط العام + الخطوط + SEO
  page.tsx            الصفحة الرئيسية
  globals.css         الأنماط العامة ومتغيرات التصميم
components/           عناصر الواجهة القابلة لإعادة الاستخدام
lib/content.ts        محتوى الشركة (مستخرج من ملف Company Profile)
public/images/        الشعار وصور المشاريع
```

## الصفحة الرئيسية — الحالة الحالية

تم بناء الصفحة الرئيسية بالكامل بأقسامها:
Hero، من نحن، خدماتنا، أبرز المشاريع، لماذا ستركونيك (مع عدادات متحركة)،
مراحل التنفيذ، المدونة، الأسئلة الشائعة، دعوة للتواصل، فوتر كامل،
بالإضافة إلى: زر واتساب عائم، زر العودة للأعلى، مؤشر تقدم التصفح،
إشعار الكوكيز، ووضع ليلي (زر في الهيدر).

## الصفحات القادمة

من نحن (تفصيلية)، خدماتنا (تفصيلية)، مشاريعنا (مع تصنيف ومعرض Lightbox)،
القطاعات، فريق العمل، الوظائف، المدونة، تواصل معنا (نموذج + خريطة).

## ملاحظة هامة

قسم "التراخيص" لم يُدرج بعد لعدم توفر أرقام تراخيص/شهادات فعلية من الشركة
بخلاف الرقم الضريبي والسجل التجاري المتوفرين حالياً في `lib/content.ts` وفي الفوتر.
